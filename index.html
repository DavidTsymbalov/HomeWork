Возможности

In every tool, at every step

Tab, Agent и inline-правки — без переключения между редактором и отдельным чатом.

  • 01 / Tab

    Умное автодополнение

    Cursor предлагает целые блоки по контексту файла. Tab — принять. Esc — продолжить самому.

  • 02 / Agent

    Агент по всему проекту

    Опишите задачу — агент найдёт файлы, внесёт правки, предложит тесты и покажет аккуратный diff.

  • 03 / Inline

    Правки прямо в коде

    Выделите фрагмент, опишите изменение — получите патч на месте, без копирования в сторонний сервис.
