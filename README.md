# Cursor — одностраничный лендинг

Статический сайт на HTML / CSS / JS про IDE Cursor.

## Запуск локально

Откройте `index.html` в браузере или поднимите простой сервер:

```bash
python3 -m http.server 8080
```

Затем откройте http://localhost:8080

## Хостинг

Сайт полностью статический (без сборки и CDN):

- скопируйте содержимое репозитория на любой хостинг (GitHub Pages, Netlify, Vercel, Timeweb, Beget, Selectel и т.д.);
- шрифты лежат в `assets/fonts/` — Google Fonts не используются, сайт открывается из России;
- картинки — локальные SVG в `assets/images/`.

## Возможности

- светлая / тёмная тема с сохранением выбора;
- анимации появления секций и героя;
- профессиональная типографика (Unbounded + IBM Plex Sans / Mono);
- адаптивная вёрстка с акцентом на десктоп.
